# 🧠 Overview

Cuvoria is an intelligent healthcare recommendation platform designed to help users discover the most suitable hospitals using real-world healthcare intelligence.

The system combines:

* 📊 Data Analytics
* 🗺 Geospatial Intelligence
* 🤖 AI-Powered Assistance
* 🏥 Hospital Recommendation Logic

to deliver fast, accurate, and reliable healthcare recommendations.

---

# ✨ Key Features

* 🏥 Smart hospital recommendations based on user requirements
* 📍 Distance-aware ranking using geospatial calculations
* ⭐ Hybrid scoring system using:

  * Ratings
  * Distance
  * Availability
  * Specialization
* 📊 Interactive analytics dashboard
* 🗺 Real-time hospital visualization with Folium maps
* 🤖 Luna AI Assistant for conversational healthcare guidance
* 🚑 Emergency mode for quick nearest-hospital access
* 💾 Save & bookmark preferred hospitals
* 🌙 Modern responsive dark UI

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/Cuvoria-Smart-Hospital-Recommendation-System.git

cd Cuvoria-Smart-Hospital-Recommendation-System
```

---

## 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 3️⃣ Configure API Key

Create:

```bash
.streamlit/secrets.toml
```

Add:

```toml
GROQ_API_KEY = "your_api_key_here"
```

---

## 4️⃣ Run Application

```bash
streamlit run app.py
```
